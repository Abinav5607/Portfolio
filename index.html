Projects

Magnetic Levitation Train Prototype

A small-scale maglev train built on an electromagnet-assisted track using N42 neodymium magnets (42 MGOe), coils driven at 24V DC (~200 turns each on quarter-inch steel bolts, ~6A, eight-plus coils), and MOSFET switching protected by 1N4007 flyback diodes. Optical emitter–receiver sensors detect the passing train to trigger automatic coil control, while an added remote-control system enables manual operation and better stopping — with ball bearings replacing friction braking, and a wider, longer, stabilized body to prevent tipping.

ElectronicsEmbedded ControlPrototyping

Intelligent AI Helpdesk Chatbot — IIIT Hyderabad

A Retrieval-Augmented Generation (RAG) system that lets users search past support issues using natural language instead of exact keyword matches. It connects to IIIT Hyderabad's Redmine issue tracker over an SSH-tunnelled MariaDB connection, generates semantic embeddings of issue data with the Nomic embedding model via Ollama, and stores them in a ChromaDB vector database — so a query is embedded and matched against past issues by meaning, even when the wording is completely different.

RAGVector SearchPython

Exam Scheduling System

A PHP-based system that automatically generates and validates examination timetables from course-slot assignments. It detects clashes by comparing student registration data across courses, blocks generation until conflicts are resolved, and applies an iterative pairwise slot-exchange heuristic to minimize consecutive exams — replacing a manual, error-prone process with systematic, algorithmic checks.

PHPMySQLAlgorithms

Projects

Magnetic Levitation Train

Designed and built a small-scale magnetic levitation train prototype using eight electromagnetic coils (~200 turns each on quarter-inch steel bolts, driven at 6A/24V) switched via MOSFETs with 1N4007 flyback diode protection. Track-side optical sensors trigger coil switching as the train passes, while a commutator reverses current direction and a remote control enables manual stop control. N42 neodymium magnets provide lift, and ball bearings replace friction braking to cut heat and wear, with a wide, long-stabilized chassis to prevent tipping.

ElectronicsElectromagneticsPrototyping

AI Helpdesk Chatbot — IIIT Hyderabad

Created an AI-powered helpdesk chatbot for IIIT Hyderabad that retrieves relevant support issues using natural language instead of exact keyword matches. The system connects to the institute's Redmine issue tracker over an SSH-tunnelled MariaDB connection, generates semantic embeddings of issue data with the Nomic embedding model via Ollama, and stores them in a ChromaDB vector database for similarity search — forming a Retrieval-Augmented Generation (RAG) pipeline that surfaces related past issues for any query.

RAGChromaDBOllamaPython

Exam Scheduling System

Built a PHP-based exam timetable system that generates and validates examination schedules from course-slot assignments. It detects scheduling clashes by comparing student registration data across courses, blocks timetable generation until conflicts are resolved, and applies an iterative pairwise slot-exchange heuristic to minimize consecutive examinations, rendering the final timetable through a three-stage input, validation, and generation workflow.
